# PPG 脉搏波形质量评估与改进建议

> 评估对象：基于 AFE4490 的串口屏血氧/脉搏监护界面截图
> 评估结论：**当前波形不符合医院监护仪标准，差距较大**

---

## 一、结论速览

当前屏幕显示的 PPG（光电容积脉搏波）波形充满高频毛刺并伴随大幅基线漂移，无法分辨出独立的脉搏周期，与医院级监护仪应有的光滑、周期性脉冲波形态相差明显。同时界面数值与波形、报警逻辑之间存在自相矛盾，未达到临床监护设备的可信度要求。

---

## 二、波形形态对比

### 医院监护仪标准 PPG
- 每个心动周期对应一个清晰、光滑的脉冲波
- 形态结构完整：**快速收缩期上升支 → 主波峰 → 重搏切迹 → 平滑舒张期下降**
- 基线平稳，噪声极小
- 波形频率与显示的 PR（脉率）严格一致

### 当前屏幕波形
- 密集锯齿状高频毛刺（疑似工频干扰、环境光干扰或接触不良）
- 整体叠加缓慢的大幅基线漂移（呼吸、手指按压变化或运动伪差）
- 完全分辨不出单次脉搏波形
- 形态与显示的 PR 数值不匹配

---

## 三、数据自相矛盾（医院设备不会出现）

| 问题项 | 现状 | 应有效果 |
|--------|------|----------|
| PR 数值 | 208 bpm | 静息状态下稳定 208 几乎不可能，大概率为误算 |
| 报警逻辑 | PR 已超 120 bpm 上限却无报警、无报警记录 | 必须触发声光报警并写入报警记录 |
| 信号质量 | 显示 100（满格） | 与实际波形质量严重不符，评价算法未真正工作 |
| SpO₂ | 97%（单看正常） | 在该信噪比下数值可信度存疑 |

**误算根因推测**：高频毛刺被峰值检测算法当作脉搏峰计数，导致 PR 虚高。

---

## 四、改进建议（基于 AFE4490 方案）

### 1. 硬件层面
- **遮光**：检查指夹探头是否被环境光直射（环境光是 PPG 头号干扰源）
- **接线**：探头引线是否过长、未屏蔽；建议使用屏蔽线并尽量缩短走线
- **按压**：保持手指与探头压力稳定，避免压迫过紧或过松

### 2. 数字滤波（MCU 端）
- 对 AFE4490 原始数据加 **0.5–5 Hz 带通滤波**
- 叠加 **50 Hz 工频陷波**，消除电源工频干扰
- 再叠一层**滑动平均**，波形会立刻干净很多

### 3. 峰值检测与脉率计算
- 脉搏峰之间加入**最小间隔限制**（如 250 ms，对应最高 240 bpm）
- 采用**动态阈值**判定，防止毛刺被计为心跳
- 基于真实峰间距计算 PR，避免噪声虚高

### 4. 信号质量指示（SQI）
- 用**峰-峰值一致性**或**信噪比（SNR）**真实计算信号质量
- 禁止固定显示 100，应与波形实际质量挂钩

### 5. 报警逻辑
- PR 超限时**写入报警记录**并触发声光报警
- 这是临床监护设备的硬性要求，不可缺失

---

## 五、验证路径建议

1. 先完成第 2、3 步（滤波 + 峰值检测），波形应能呈现光滑的周期性脉搏波——此时已"形似"医院设备。
2. 再补齐第 4、5 步（SQI 与报警），达到"数值可信 + 异常可报警"的临床可用性。
3. 逐项对比：波形形态、PR 与波形频率一致性、SQI 真实性、超限报警触发。
