## 〇、⚠️ 最要紧的一条：改屏文件前先关 VisualTFT

**VisualTFT 打开着工程时会周期性自动保存当前页面，会把用脚本/文本编辑器做的手工改动覆盖回去。**
2026-10-10 17:41 已实测踩到一次：刚插入的 `btn_resume` 被覆盖掉（`主界面.tft` 14275 → 13326 字节）。

因此正确顺序是：

1. **先在 VisualTFT 里关闭工程**（或直接退出 VisualTFT）；
2. 运行补丁脚本（幂等，可反复重跑）：
   ```
   cd F:\VisualTFT\SPO2_Hospital
   python tools\patch_pause_button.py
   ```
   它会：① 在 `主界面.tft` 插入 `btn_resume(id=6)`（"继续监护"，排在 `btn_pause` 之前）；
   ② 把 7 个页面的时钟 `txt_clock(92)` 统一成 `format=1 / "%y-%n-%d %h:%m:%s" / input=0`；
   ③ 打印校验结果（两个按钮的顺序、switch 值）。
3. **再打开 VisualTFT** → 重新编译工程 → 下载屏固件。此时它读到的就是改好的文件。

> 如果哪天发现按钮又变回"暂停监护 / 点了没反应"，先看看 VisualTFT 是不是又开着覆盖了，
> 关掉它重跑一次补丁脚本即可。

## 二、逐项验证

### 0. 本轮三项（最优先，对应 5.3）

**① 暂停按钮文字 暂停监护 → 继续监护**
- [ ] 主界面左下角一开始应显示 **"暂停监护"**。
- [ ] 点它 → 暂停页 → 点 **确认** → 回到主界面，左下角按钮应变成 **"继续监护"**。
- [ ] 再点 **"继续监护"** → 立即恢复监护，按钮文字回到 **"暂停监护"**。

**② 波形下方文案 脉搏波采集中 → 暂停中**
- [ ] 正常时波形下方是 **"脉搏波采集中"**，右上角小字是 **"测量有效"**。
- [ ] 暂停后应变 **"暂停中"** / **"已暂停"**；恢复后变回。

**③ 监护时间正常走秒**
- [ ] 主界面右下角 `监护时间` 应 **每秒 +1**，形如 `监护时间 00:00:37`。
- [ ] 暂停期间应 **冻结不动**（不是清零），恢复后从暂停处继续。
- [ ] 若停在 `00:00:01` 不动 → 说明屏里还是带旧 Lua 的老固件，**重新编译下载屏固件**即可。

### 1. 暂停监护「真停测 + 文案变」
- [ ] 主界面点 **暂停监护** → 进暂停页 → 点 **确认**。
- [ ] 期望：**PPG 波形停止滚动、SpO₂/PR 数值变 `--`**；文案按上面 ①②③ 变化。
- [ ] 暂停页的提示语应显示 **"当前监护中, 确认暂停监护?"**；已暂停时再点"暂停监护"则显示 **"当前已暂停, 确认恢复监护?"**。
- [ ] 恢复：点主界面 **"继续监护"**，或在暂停页再点一次 **确认**。
- [ ] 暂停期间报警判定应停（状态文案回 **"正常"**），不再落新记录。

### 2. 趋势「按 60s 落点 + 时段可切」
- [ ] 让设备连续跑 **≥ 3 分钟**，进趋势页看是否 **每 60 秒冒一个点**。
- [ ] 点 **30min / 2h / 8h** → 时段文本与曲线横轴点数应随之变化。
- [ ] 说明：`sample_cycle="60"` 是屏控件属性，**60s 一点是设计值**，不是卡顿。

### 3. 报警记录「有异常就落一条」
- [ ] 设置页把 **SpO₂ 下限** 改到高于当前值（如 99），屏息几秒。
- [ ] 期望：越限**持续 3 秒**后新增一条记录（时间 / 事件 / 级别 / 状态），并**听到提示音**。
- [ ] 报警记录页点 **清空** → 4 行清空并显示 **"暂无报警记录"**。
- [ ] 判定规则：越限需连续 3s（防抖）；回落到 SpO₂≥92 / PR≤115 才解除。

### 4. 设置「阈值 / 亮度 / 声音 真生效」
- [ ] 改 **SpO₂ 下限 / PR 上限** → 主界面 **"报警限值 90-100 %" / "报警高限 120 bpm"** 文案应立刻联动；且**越限判定按新阈值**执行。
- [ ] 拖 **亮度滑块** → **屏背光真的变亮/变暗**（映射到 `EE 60`，0=最亮），且 `12` 处的百分比文本跟着变。
- [ ] 点 **声音提示** 开关 → `13` 文案在 **"声音提示已开启 / 已关闭"** 间切换；下次报警 **有/无蜂鸣**。
- [ ] 以上文案原先指望屏端 Lua，现在全部由 MCU 写。

### 5. 时间「带年月日，与血压一致」
- [ ] 顶栏时钟应显示 **`2026-01-01 00:00:00`** 这类 **4 位年 + 月 + 日 + 时:分:秒**，并逐秒走。
- [ ] 与血压屏（`2026-01-01 00:00:00`）格式一致。
- [ ] 想改起始日期：改 `app_bloodoxygen.c` 顶部 `RTC_INIT_YEAR / RTC_INIT_MON / RTC_INIT_DAY`。
- [ ] 时间由 MCU 每 5 分钟同步给屏；**屏上不可手改**（`input="0"`，避免被同步覆盖）。
- [ ] 注意：监护时间（右下角）和顶栏时钟是**两回事**——前者是"已监护时长"，后者是"墙上时间"。

### 6. 探头「拔下就变未接入」
- [ ] **拔下指套**几秒后 → 各页状态条由 **"探头已接入"** 变 **"探头未接入"**。
- [ ] 夹回后恢复。原理：UNO 帧 `spo2==0` 视为无效 → 判为未接入。

## 三、若某项不符，先查这几处

| 现象 | 先查 |
|---|---|
| 全屏中文变乱码 | 屏固件没下载新版（字库/文本不匹配），或 `.tft` 被 VisualTFT 回写 |
| 时钟仍是 `HH:MM:SS` | 屏固件没重新编译下载（MCU 侧改不了 RTC 显示格式） |
| 时钟日期不对但不走秒 | 屏 RTC 未被 `EE 81` 写入；看 USART1 是否有 RTC 相关回帧 |
| **按钮文字不切换 / 恢复按钮点了没反应** | ① 屏固件没重新编译下载（`btn_resume` 在屏里还不存在）；② VisualTFT 又覆盖了 `主界面.tft` → 关掉它重跑 `tools\patch_pause_button.py` |
| **监护时间停在 `00:00:01`** | 屏里还是**带旧 Lua 的老固件**（旧脚本 `start_timer(...,repeat=1)` 只触发一次）。重新编译并下载屏固件即可 |
| **暂停后"脉搏波采集中"不变** | 同上：屏固件旧 / MCU 固件没重烧 |
| 暂停后仍在测 | 屏"暂停页确认键"通知未上报（`notify_disable` / 按钮属性） |
| 数值/波形正常但报警不落记录 | 越限未持续满 3s，或阈值钳位把设置值丢弃（SpO₂ 限 70~99、PR 限 60~200） |
| 设置页改了阈值，主界面限值文案不变 | `NotifyText()` 未触发（文本输入控件未上报）→ 看 USART1 是否有 `EE B1 11` 帧 |
| 背光滑块无效 | `EE 60` 参数是**反相**的（0=最亮）；确认屏口波特率 115200 |
