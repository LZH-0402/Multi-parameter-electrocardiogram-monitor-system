# 血压测量「正常范围判定」代码速查文档

> 用途：快速查阅代码里「测量数据是哪些、在哪里被处理、屏上显示什么提示词」，
> 以及「正常 / 异常」判定范围与提示词。
>
> ✅ **已落地**：本功能已在 `STM32F407_BP/HARDWARE/app_bp.c` 实现（步骤7），
> 见第 4 节「实际代码」；下方「当前代码行为 / 建议判定范围」为历史参考，现已生效。

---

## 0. 一句话结论

当前 `result` 分支只把收缩压 / 舒张压 / 脉率三个**原始数值**写到屏幕，**从不判断**它们是否落在正常区间；
屏上唯一带临床含义的提示是「**心率不齐**」（来自传感器报文的 bit7 标志）。
所有「偏高 / 偏低 / 高血压 / 低血压」均为本文建议补充内容。

## 1. 测量数据在代码里的流转位置（速查表）

| 环节 | 文件 | 位置 / 符号 | 当前做了什么 |
|------|------|------------|-------------|
| 协议解析结果结构体 | `HARDWARE/bp_sensor.h` | `bp_result_t`（约 44–49 行） | 定义 `systolic` / `diastolic` / `heart_rate` / `irregular` 四个字段，无「是否正常」字段 |
| 解析出结果帧 | `HARDWARE/bp_sensor.c` | `bp_parse_result()` | 把 `0xAC` 帧的 `SSYH/SSYL/SZYH/SZYL/XL` 拆成上述四个字段 |
| 收到结果帧回调 | `HARDWARE/app_bp.c` | `on_bp_frame()` 的 `case BP_CMD_RESULT:`（约 1211–1247 行） | 存进 `s_last`、调用 `result_show()`、记一条历史、切到结果页 |
| 写到结果页控件 | `HARDWARE/app_bp.c` | `result_show()`（约 907–914 行） | 把 `s_last.sys / dia / pr` 直接 `u32_dec` 写进控件 110/111/112（**无比较、无分级**） |
| 屏上提示词 | `HARDWARE/app_bp.c` | `on_bp_frame()` 约 1240–1242 行 | `TIP_TITLE` 写「测量完成」；`TIP_DETAIL` 仅在 `irregular=1` 时写「心率不齐，请由专业医护人员评估」，否则写空 |
| 历史记录 | `HARDWARE/app_bp.c` | `hist_add()` | 存 `sys/dia/pr/irregular` 与时间戳，状态码 1=成功，同样不分级 |

> 注：`s_last` 是 `bp_last_t` 类型（位于 `app_bp.c` 顶部状态变量区），含 `valid/sys/dia/pr/irregular/year/mon/day/hour/min`。

## 2. 当前代码里「已存在」的判断 / 提示词

只有两条，都不是正常 / 异常分级，列出来避免混淆：

1. **心率不齐提示（已实现）**
   - 来源：`bp_result_t.irregular`（= `SSYH` 的 bit7，见 `bp_sensor.h`）。
   - 屏上表现：结果页 `TIP_DETAIL(104)` 控件显示
     `心率不齐，请由专业医护人员评估`；正常时该控件为空。
   - 代码位置：`app_bp.c` 约 1242 行
     ```c
     hmi_write_text(HMI_SCREEN_RESULT, HMI_CTRL_TIP_DETAIL,
                    r.irregular ? "\xBD\xDA\xC2\xC9\xCC\xE1\xCA\xBE\xA3\xAC\xC7\xEB\xD3\xC2\xD2\xBD\xBB\xA4\xC8\xCB\xD4\xB1\xB8\xB4\xBA\xCB"
                                : "");
     ```

2. **超压保护（传感器侧，非分级）**
   - 来源：传感器错误码 `3`（`BP_ERR_OVERPRESS`，`bp_sensor.h` 约 37–40 行），
     含义「气袋压力超过 **295 mmHg**」。
   - 这是测量失败保护，不是血压值过高提示。

其余（`0=测不到脉搏 / 1=打气不上 50mmHg / 2=数值有误 / 4=干预过多`）都是**测量过程错误码**，与「血压正常与否」无关。

## 3. 建议补充的「正常范围判定」与屏上提示词（待实现）

> 以下为**标准成人静息态临床参考范围**（依据中国高血压防治指南 / AHA 常用分界），
> 供你快速查阅；若要落地，需作为新常量加入代码并在 `result_show()` 里做比较。

### 3.1 收缩压 SYS（mmHg）

| 区间 | 分级 | 建议屏上提示词 |
|------|------|---------------|
| `< 90` | 偏低（低血压） | `血压偏低，请关注` |
| `90 – 139` | **正常** | （可不提示 / `血压正常`） |
| `140 – 159` | 偏高（高血压 1 级） | `血压偏高，请注意` |
| `≥ 160` | 高血压（2 级及以上） | `血压过高，建议就医` |

### 3.2 舒张压 DIA（mmHg）

| 区间 | 分级 | 建议屏上提示词 |
|------|------|---------------|
| `< 60` | 偏低（低血压） | `舒张压偏低，请关注` |
| `60 – 89` | **正常** | （可不提示 / `血压正常`） |
| `90 – 99` | 偏高（高血压 1 级） | `舒张压偏高，请注意` |
| `≥ 100` | 高血压（2 级及以上） | `舒张压过高，建议就医` |

### 3.3 脉率 PR（bpm）

| 区间 | 分级 | 建议屏上提示词 |
|------|------|---------------|
| `< 60` | 偏慢（心动过缓） | `心率偏慢，请关注` |
| `60 – 100` | **正常** | （可不提示 / `心率正常`） |
| `> 100` | 偏快（心动过速） | `心率偏快，请注意` |

### 3.4 判定建议（如何合并三个量）

- **正常**：SYS 与 DIA 都落在正常区间，且 PR 正常 → 结果页可显示「血压正常」。
- **异常**：任一超出则按**最严重**那一项给提示词（优先顺序建议 `≥160/≥100 高血压` > `偏高` > `偏低`）。
- 诊断以**收缩压 / 舒张压中较高分级**为准（指南常规做法）。
- 提示词建议写到结果页 `TIP_TITLE(103)` / `TIP_DETAIL(104)`，与现有「心率不齐」提示共用同一组控件。

## 4. 建议实现代码（尚未加入工程，仅作参考）

> 落地时建议新增一组范围常量 + 一个分级函数，在 `result_show()` 里调用。
> ⚠️ 工程用 Keil AC5，**所有屏上中文必须用 GBK `\xNN` 转义**（源文件保持纯 ASCII），不能直接写 UTF-8 中文。

```c
/* —— 建议新增：正常范围常量（app_bp.c 顶部宏区） —— */
#define BP_SYS_NORMAL_LO  90u
#define BP_SYS_NORMAL_HI  139u
#define BP_SYS_HIGH1_LO   140u   /* 高血压 1 级下限 */
#define BP_SYS_HIGH2_LO   160u   /* 高血压 2 级下限 */
#define BP_DIA_NORMAL_LO  60u
#define BP_DIA_NORMAL_HI  89u
#define BP_DIA_HIGH1_LO   90u
#define BP_DIA_HIGH2_LO   100u
#define BP_PR_NORMAL_LO   60u
#define BP_PR_NORMAL_HI   100u

/* —— 建议新增：分级函数，返回屏上提示词（GBK 转义串） —— */
static const char *bp_classify(uint16_t sys, uint16_t dia, uint8_t pr)
{
    uint8_t lvl = 0;   /* 0=正常 1=偏低 2=偏高 3=高血压 */
    if (sys < BP_SYS_NORMAL_LO || dia < BP_DIA_NORMAL_LO) lvl = 1;
    if (sys >= BP_SYS_HIGH2_LO || dia >= BP_DIA_HIGH2_LO) lvl = 3;
    else if (sys >= BP_SYS_HIGH1_LO || dia >= BP_DIA_HIGH1_LO) lvl = 2;
    if (pr > BP_PR_NORMAL_HI) lvl = (lvl < 2) ? 2 : lvl;   /* 心率偏快至少算偏高 */
    if (pr < BP_PR_NORMAL_LO)  lvl = (lvl == 0) ? 1 : lvl; /* 心率偏慢算偏低 */

    switch (lvl) {
        case 1:  return "\xD1\xC6\xD1\xC5\xC6\xF0\xB5\xCD\xA3\xAC\xC7\xEB\xB9\xD8\xD7\xA2"; /* 血压偏低，请关注 */
        case 2:  return "\xD1\xC5\xD1\xC5\xC6\xF0\xB8\xDF\xA3\xAC\xC7\xEB\xD7\xA2\xD2\xE2"; /* 血压偏高，请注意 */
        case 3:  return "\xD1\xC5\xD1\xC5\xB9\xFD\xB8\xDF\xA3\xAC\xBD\xA8\xD2\xE3\xBE\xC3\xD2\xBD"; /* 血压过高，建议就医 */
        default: return "\xD1\xC5\xD1\xC5\xD5\xFD\xB3\xA3";                                 /* 血压正常 */
    }
}

/* —— 在 result_show() 里调用（约 912 行之后追加） —— */
hmi_write_text(HMI_SCREEN_RESULT, HMI_CTRL_TIP_DETAIL, bp_classify(s_last.sys, s_last.dia, s_last.pr));
```

> 提示词字符串的 `\xNN` 是 GBK 编码，需按实际字库核对；上面仅为示意，落地前请用 GBK 编码工具确认每个汉字的两字节值。
