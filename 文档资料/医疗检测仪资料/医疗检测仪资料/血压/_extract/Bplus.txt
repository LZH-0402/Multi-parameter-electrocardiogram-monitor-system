一、产品概述
HKB-08B+血压传感器的量程与精度执行了电子血压计国家标准，不仅可以测量收缩压
和舒张压，还可以测量指定压力下的肱动脉脉搏波形。该产品有 USB、RS232、UART（TTL）
三种数字接口可供选择。
二、技术参数
 工作电压：5 VDC；
 工作电流：350 ~ 500 mA（气泵、气阀为主要功耗部件）；
 测量范围：0 ~ 300 mmHg；
 分辨率：1 mmHg；
 测量精度：静态 1 mmHg，动态 3 mmHg；
 袖带容量：2 L；
 通信波特率：115200 bps；
 通信接口：USB、RS232、UART（TTL）。

三、通信协议
采用全双工串行通讯接口，1 个起始位、8 个数据位、1 个停止位、无奇偶校验位，波特
率 115200 bps。
1.数据帧格式
帧头标识 固定为 0xFF 0xC0
长度 长度字节，校验和，命令及后面所有数据的个数
校验和 CKSUM 包括长度，命令及其之后的所有字节和的低字节
命令 0xA0/0xA1/0xA8/0xAA/0xD0/0xD1/0xD2
BYTE 1 数据内容，根据数据标识有不同的意义和格式
BYTE 2
……
BYTE n
复位
0xFF 0x00（收到此指令后，停止所有工作，包括气泵、气阀等，并
保持唤醒状态。此指令无需回复，仅有两个字节，且没有帧头。）
2.控制命令及对应数据格式说明
 血压测量
（1）休眠传感器
特征代码：0xA8
通讯过程描述：
上位机 →→ 传感器： 0xFF 0xC0 0x03 CKSUM 0xA8
上位机 ←← 传感器(应答)： 0xFF 0xC0 0x03 CKSUM 0xA8
说明：
关机命令，收到此指令，传感器进入休眠状态。如果在测量状态下收到此指令，先
停止测量，再进入休眠状态。

上位机 →→ 传感器： 0xFF 0xC0 0x03 CKSUM 0xAA
上位机 ←← 传感器(应答)： 0xFF 0xC0 0x03 CKSUM 0xAA

（3）启动测量
特征代码：0xA0
通讯过程描述：
上位机 →→ 传感器： 0xFF 0xC0 0x03 CKSUM 0xA0
上位机 ←← 传感器(应答)： 0xFF 0xC0 0x05 CKSUM 0xA0 QYH QYL
测量结果：0xFF 0xC0 0x08 CKSUM 0xAC SSYH SSYL SZYH SZYL XL
说明：
QYH：测量过程中气压输出高字节，其中 QYH.4=1 表示有心跳，QYH.4=0 表示无心跳；
QYL：气压输出低字节；
SZYH、SZYL：舒张压；
SSYH、SSYL：收缩压，其中 SSYH.7=1 表示心率不齐，SSYH.7=0 表示心率正常；
XL：心率。
错误报告：0xFF 0xC0 0x04 CKSUM 0xAD X
说明：
X=0 表示测量不到有效的脉搏；
X=1 表示 11s 内打气不上 50mmHg（气袋没绑好）；
X=2 表示测量结果数值有误；
X=3 表示气袋压力超过 295mmHg，进入超压保护；
X=4 表示干预过多（测量中移动、说话等）。

四、校验和计算
unsigned char CKSUM0 (unsigned char dat[],unsigned int num)
{
unsigned char CKSUM_num = 0;
unsigned int i = 0;
for (i = 0; i < num; i++)
{
if (i == 0)
CKSUM_num = dat[0];
else
CKSUM_num = CKSUM_num + dat[i];
}
return CKSUM_num;
}
