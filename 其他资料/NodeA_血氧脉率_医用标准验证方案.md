# Node-A 血氧(SpO₂)/脉率(PR) 医用标准符合性测试方案

> **文档定位**：指导用工程/研发手段，验证本样机（Node-A，STM32F407 + AFE4490/UNO 中转）的血氧与脉率是否满足医用相关标准的核心要求——**精度、报警延迟、抗运动、抗弱灌注**，为后续正式注册/认证积累摸底数据。
>
> **免责声明**：本方案是**内部研发自测指南**，**不等同于**第三方型式检验/注册检验。正式合规须由具备 CMA/CNAS 资质的检测机构，按标准**现行版本**执行并出具报告。文中具体限值（如 A_rms ≤1%、报警延迟 ≤15s 等）为行业常见要求与回忆值，**最终以标准原文现行文本为准**。

## 1. 适用标准与中文代号对照

| 标准 | 中文代号 / 别名 | 主要覆盖 |
|------|----------------|----------|
| **IEC 60601-1** (+A1) / **GB 9706.1-2020** | 医用电气设备 通用安全 | 基本安全 + 基本性能：电气安全、漏电流、机械、温升、单一故障、EMC（部分） |
| **IEC 60601-2-61:2009** / **YY 0784-2010** | 脉搏血氧仪设备 专用要求 | SpO₂/PR 专用：**精度(A_rms)、报警、低灌注、运动、标签、报警音** ← 主标准 |
| **ISO 9919:2005** | 医用脉搏血氧仪设备 | SpO₂ 专用（旧框架，与 60601-2-61 重叠；新设备走 60601-2-61） |
| **IEC 60601-2-27:2011** / **YY 9706.227** / (旧 GB 9706.25) | 病人监护设备 专用要求 | 监护仪通用：报警系统、优先级、延迟、显示可读性 |
| **IEC 60601-1-2** / **YY 0505** / **GB 9706.1-2** | 电磁兼容 | 辐射发射 / 抗扰度（与 SpO₂ 性能交叉：抗扰度下精度不劣化） |
| **ISO 81060-1/2** | 无创血压 | 本项目 NIBP 部分（本文聚焦 SpO₂/PR，NIBP 另行参照） |

> 你提到的 **YY 0784 = IEC 60601-2-61 的中文版**（SpO₂ 主标准）；**60601-2-27** 是监护仪通用；**60601-1** 是通用安全。三者基本覆盖一个血氧监护模块的"安全 + 性能 + 报警"。

## 2. 总体验证策略

- **金标准（参考设备）**：
  - 血氧对照首选 **CO-oximetry 血气分析仪**测得的 SaO₂，或**已注册的参考血氧仪**（Nellcor / Masimo / Philips 等同侧同指测量）；
  - 脉率对照用**同步 ECG 导联**或参考监护仪心率。
- **更可复现的方法**：用 **SpO₂ 模拟器**（如 Fluke ProSim / Index2 系列）注入可调 SpO₂(50–100%)、可调灌注指数(PI)、可调运动噪声——免人体、免低氧气体、可重复，是摸底首选；**人体 + 低氧混合气体**作为补充验证。
- **受试者/样本**：ISO 9919 / 60601-2-61 通常要求 ≥10–20 名、覆盖不同肤色/年龄/灌注状态，且数据对必须覆盖 **70%–100%** 区间（含低值段，不能只测健康高值）。
- **环境**：温度 18–28℃、湿度 30–75%、稳定照明（排除强光对光电探头的干扰）、电磁环境干净或按要求做 EMC 抗扰度。
- **时间同步**：设备值与参考值必须**时间戳对齐**（统一 NTP 或共触发），否则精度/报警延迟无法成对计算。

## 3. 测试项目详解

### 3.1 精度（Accuracy）

#### 3.1.1 SpO₂ 精度
- **方法**：使真实或模拟 SpO₂ 覆盖 70%–100%，每个点同时记录「设备值 − 参考值」≥ N 对（每点建议 ≥30 对）。
- **核心指标**：
  - **A_rms**（均方根误差） = `sqrt( mean( Dev_i² ) )`，`Dev = 设备SpO₂ − 参考SpO₂`
  - **bias**（平均偏差）、**95% 一致性限值（LoA，Bland-Altman）**
- **判定（据 60601-2-61 / ISO 9919 常见要求）**：70%–100% 区间 **A_rms ≤ 1%**（部分厂商标 ≤2% 亦可，但须声明）；80%–100% 区间通常更严。低灌注/运动下可放宽但必须注明。
- **落地点**：用本设备的 `g_meas.spo2`（经 USART1 调试串口或 CAN 2120.SpO₂ 读出）与参考值成对比。⚠️ 验证前务必确认**探头已接入、信号稳定**（见 §6 现状）。

#### 3.1.2 脉率（PR）精度
- **方法**：同步记录设备 PR 与 ECG/参考 HR，覆盖 40–200 bpm（含心动过缓/过速段）。
- **判定（常见要求）**：**±3 bpm**（或 ±5%）。逐拍或逐秒比较。
- **注意**：本设备 PR 来自 IR 波形峰检，运动/弱灌注下可能暂时丢失，需在"有效段"内统计精度。

### 3.2 报警延迟（Alarm latency）
- **定义**：从生理事件（SpO₂ 跌破阈值 / 脉率越界 / 停搏）发生时刻，到设备给出**有效报警**（声+光+界面）的时刻之差。
- **方法**：诱导阶跃变化——模拟器快速降到阈值下，或注入心率失常/停搏模拟；记录事件时刻 T0 与报警时刻 T1。
- **判定（据 60601-2-27 / 60601-2-61）**：高优先级报警延迟通常 **≤ 15–20 s**（具体以标准与设备声明上限为准）；重复 ≥10 次取**最大延迟**。
- **本项目注意**：报警在**哪一端产生**（MCU 端 vs 血氧屏端 USART2 显示）会影响链路延迟；需把 `2100:01`(epoch) 打在事件与报警上，并核算屏端渲染 + 串口传输延迟是否计入。

### 3.3 抗运动（Motion artifact rejection）
- **方法**：受试者做标准化动作——手指敲桌、手臂甩动、原地踏步、握拳-放松，每类 ≥1–2 min，期间同步采设备值与参考值。
- **评价**：
  - 运动状态 vs 静止基线的 **A_rms 对比**；
  - **误报警计数**（假高/假低/持续丢失）。
- **判定（工程建议，非标准硬限值）**：运动下 SpO₂ A_rms ≤ 3–5% 且无持续性偏差；**不产生危及生命的高优先级假报警**；PR 可短暂丢失但恢复后追平。
- **本项目落地点**：结合 `2130:01` 的 `DV_WAVE_VALID` / F407 `signal_quality`(SQI) 与运动期波形抖动评估；运动/弱灌注应如实反映到 flags 与 SQI，避免"乱动却报正常"。

### 3.4 抗弱灌注（Low / weak perfusion）
- **方法**：用 PI 可调的**灌注模拟器**注入 PI 低至声明下限（典型医用级 **0.02%–0.1%**）的脉动信号；或选低灌注真实受试者（受冷、低血压、休克早期）。
- **评价**：设备能否在 PI 低至下限时仍给出 SpO₂/PR，并正确显示/报警。
- **判定**：按设备声明的"最低可测 PI"验证；低于下限可**不保证**但不应给出**错误高值 / 假正常**（这是安全红线）。
- **本项目落地点**：AFE4490 本身支持极低灌注（LED 电流 8 位可编程、TIA 增益可调）；需在固件侧确认 `g_meas.signal_quality` 与 `result_valid` 在弱灌注下的阈值——防止"测不准却报正常值"。

### 3.5 抗扰度（交叉项，来自 60601-1-2 / EMC）
- 在辐射/传导/静电/工频磁场等抗扰度测试下，SpO₂/PR 精度不应出现不可接受劣化或危险误报警。建议作为精度测试的"环境变体"一并记录。

## 4. 数据采集与比对实施（针对 Node-A 工程）

**数据出口（任选其一或并用）**：
1. **USART1 (115200) 调试串口**：打印 epoch / SpO₂ / PR / SQI / flags（最直接）；
2. **CAN**：TPDO3(2120) SpO₂(×100)/PR(×100) + TPDO1(2110) ir_wave + TPDO5(2130) flags；
3. **血氧屏趋势**（即你截图看到的那张图）。

**建议流程**：
1. 用 CAN 或 USART1 把设备值**逐秒**落盘为 CSV；
2. 参考设备（模拟器/认证仪）同步记录（同样逐秒或逐拍）；
3. 按时间戳对齐后成对计算误差。

**必记字段模板（CSV）**：
```
ts, dev_spo2, ref_spo2, dev_pr, ref_pr, pi_or_sqi, motion, alarm_active
```

> ⚠️ **前置条件（来自实测经验）**：验证前先确认屏幕**不再显示"探头未接入"**。此前两张截图的对比已说明——探头断开时 SpO₂/PR 是噪声/伪值，**不能用于精度评估**，必须先接好探头、稳定后再测。

## 5. 统计与报告模板

| 项目 | 输出指标 |
|------|----------|
| 精度 | A_rms、bias(mean)、95% LoA、相关系数；按区间 **70–80 / 80–90 / 90–100** 分别统计 |
| 报警延迟 | 最大值 / 中位数 / P95 |
| 运动 | 分场景 A_rms 与静止对比、误报警计数、可用率(%) |
| 弱灌注 | 最低可测 PI、该 PI 下的 A_rms 与可用率 |

建议每轮测试产出一个**一页纸判定表**：测试条件 / 样本量 / 结果 / 是否达标 / 偏差说明。

## 6. 当前样机验证就绪度（工程侧提醒）

结合此前两轮截图与项目现状，正式送检前建议先解决：

1. **信号有效性门控**：确保"探头未接入/弱信号"时**不输出正常值**，而是显式标无效（`2130:01` 的 `DV_SPO2_VALID`/`DV_PPG_VALID` 位、屏端 `--`）；否则精度统计会被伪值污染。
2. **SpO₂ 刷新时延**：已知 UNO 端 `estimate_spo2()` 约每 2s 刷新一次（方案A 后），验证时精度判定应取"已稳定段"而非突变段。
3. **SQI/灌注判定阈值**：`signal_quality` 与 `result_valid` 在弱灌注/运动下的阈值需与模拟器 PI 标定对齐，作为"抗弱灌注"合格的判定依据。
4. **报警产生位置与延迟链路**：明确报警在 MCU 还是屏端产生，并把延迟（含 USART2 传输）计入 §3.2 考核。

## 7. 与正式认证的区别（重要）

- 本方案是**研发自测/摸底**，可作为注册检前的"查漏补缺"，但**报告不被监管机构直接采信**。
- **正式注册检验**须由具备 **CMA/CNAS** 资质的医疗器械检测机构，按标准现行版本执行并出具检测报告；且安全（GB 9706.1）、EMC（YY 0505）、生物学评价等是另一大块，注册时必需但不属本文 SpO₂/PR 性能范围。
- 软件若作为医疗器械软件（SaMD/SaMD 相关），还需走软件生存周期（IEC 62304）与网络安全等要求——超出本文范围，仅作提醒。

## 8. 术语速查

- **A_rms**：均方根精度误差，SpO₂ 精度主指标。
- **PI（Perfusion Index）**：灌注指数 = AC/DC，反映脉搏搏动强度；越低说明灌注越差。
- **CO-oximetry**：基于血液样本的光谱法血氧金标准。
- **LoA（Limits of Agreement）**：Bland-Altman 一致性限值，通常 bias ± 1.96·SD。
