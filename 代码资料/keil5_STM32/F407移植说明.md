# DCDEMO7 串口屏例程：STM32F103 → STM32F407ZGT6 移植说明

> 目标板：STM32F407ZGT6（1MB Flash / 128KB SRAM）
> 外设：大彩串口屏，接 **USART2 / PA2(TX) PA3(RX)**，波特率 19200
> 晶振：**HSE 8MHz**，主频 168MHz

---

## 一、改了哪些文件

### 新增（F4 固件库，从 `F:\嵌入式\课件资料\1_开发资料\1，STM32F4xx固件库` 复制）

| 路径 | 说明 |
|---|---|
| `Libraries\CMSIS\Core\CM4\` | core_cm4.h 等 4 个 CMSIS 内核头文件 |
| `Libraries\CMSIS\Device\STM32F4xx\Include\` | stm32f4xx.h、system_stm32f4xx.h |
| `Libraries\CMSIS\Device\STM32F4xx\Source\Templates\` | system_stm32f4xx.c |
| `Libraries\CMSIS\Device\STM32F4xx\Source\Templates\arm\` | startup_stm32f40_41xxx.s |
| `Libraries\STM32F4xx_StdPeriph_Driver\` | F4 标准外设库（31 个 .h + 36 个 .c） |

原来的 F103 库（`CMSIS\Core\CM3`、`STM32F10x_StdPeriph_Driver`）**保留未动**，可随时回退。

### 修改的库文件（2 处，很关键）

1. `Libraries\CMSIS\Device\STM32F4xx\Include\stm32f4xx.h`
   `HSE_VALUE` 由 `25000000` 改为 **`8000000`**（本板 8MHz 晶振）
2. `Libraries\CMSIS\Device\STM32F4xx\Source\Templates\system_stm32f4xx.c`
   `PLL_M` 由 `25` 改为 **`8`**
   → PLL = 8MHz / 8 × 336 / 2 = **168MHz**
3. `startup_stm32f40_41xxx.s`
   `Stack_Size` 由 1KB 改为 **2KB**（main.c 的 UpdateUI() 内有 256 字节局部数组）

## 二、顺手修掉的 3 个原工程 Bug

1. **收发串口不一致**：`UartInit()` 初始化的是 USART2(PA2/PA3)，但 `SendChar()` 和中断服务函数用的却是 USART1，而 USART1 的时钟和引脚根本没配置——发送数据实际发不出去。现已统一为同一串口。
2. **NVIC 未使能**：`Interrupts_Config()` 里没设置 `NVIC_IRQChannelSubPriority` 和 `NVIC_IRQChannelCmd`，结构体成员是随机值，串口接收中断可能压根没开。已补齐。
3. **SysTick 常量写死**：F1 用 HSI 的 48MHz，F4 是 168MHz，写死的 `48000000/100` 会让节拍和 `delay_ms()` 全部变快 3.5 倍。已改为跟随 `SystemCoreClock`。

## 三、编译与下载

1. 用 **Keil MDK5** 打开 `STM32\DCDEMO7\RVMDK\DCDEMO7.uvprojx`
2. 若提示 Device / Pack 相关错误：`Options for Target → Device` 里重新选一次 **STM32F407ZGTx**（没装 DFP 的话用 Pack Installer 装 `Keil::STM32F4xx_DFP`）
3. 确认 C/C++ 预定义宏为：`USE_STDPERIPH_DRIVER, STM32F40_41xxx`
4. 头文件路径（Options → C/C++ → Include Paths）应为 4 条：
   ```
   ..\inc
   ..\..\..\Libraries\CMSIS\Device\STM32F4xx\Include
   ..\..\..\Libraries\CMSIS\Core\CM4
   ..\..\..\Libraries\STM32F4xx_StdPeriph_Driver\inc
   ```
5. Debug 选择 ST-Link，`Flash Download` 里勾选 `Reset and Run`
6. 编译下载

### 硬件接线

| 串口屏 | STM32F407 |
|---|---|
| RX | PA2 (USART2_TX) |
| TX | PA3 (USART2_RX) |
| GND | GND |
| VCC | 按屏幕规格（通常 5V） |

> 若屏幕波特率不是 19200，改 `main.c` 里的 `UartInit(19200)`，或改 `inc\platform_config.h` 的 `HMI_USART_BAUDRATE`。

## 四、换串口 / 换引脚

只改 `STM32\DCDEMO7\inc\platform_config.h` 一组宏即可，不用动 `.c` 文件：

| 串口 | TX/RX | 需要改的宏 |
|---|---|---|
| USART1 | PA9 / PA10 | `HMI_USART`=USART1, `RCC_APB2Periph_USART1`, `USART1_IRQn`, `GPIO_AF_USART1`, Pin_9/Pin_10, PinSource9/10 |
| USART2（当前） | PA2 / PA3 | — |
| USART3 | PB10 / PB11 | `GPIO_PORT`=GPIOB, `RCC_AHB1Periph_GPIOB`, `GPIO_AF_USART3`, Pin_10/Pin_11 |
| USART6 | PC6 / PC7 | `GPIO_PORT`=GPIOC, `RCC_APB2Periph_USART6`, `USART6_IRQn`, `GPIO_AF_USART6`, Pin_6/Pin_7 |

改完还要同步两处：
- `inc\stm32f4xx_it.h` 里的中断函数声明
- `src\stm32f4xx_it.c` 里的中断函数名（如 `USART3_IRQHandler`）

## 五、后续接其它模块时的注意事项

- **加 SPI（如 AFE4490 血氧模块）**：取消 `inc\stm32f4xx_conf.h` 里 `stm32f4xx_spi.h` 的注释，并把 `Libraries\STM32F4xx_StdPeriph_Driver\src\stm32f4xx_spi.c` 加进工程。F4 的 SPI 引脚同样要 `GPIO_PinAFConfig(GPIO_AF_SPIx)`。
- **加 ADC（心电/体温采集）**：F4 的 ADC 时钟来自 **PCLK2/分频**，最高 36MHz（168MHz 下只能 4 或 6 分频），注意别超频。
- **加浮点运算**：F407 带硬件 FPU，工程已启用 FPU；做滤波/FFT 可直接用 CMSIS-DSP（固件库 `Libraries\CMSIS\DSP_Lib` 未复制，需要时再拷）。
- **栈空间**：如果后面加更多局部大数组，继续调大 `startup_stm32f40_41xxx.s` 的 `Stack_Size`。
